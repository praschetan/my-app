DEPLOY TO RAILWAY NOW
================================================================================

STEP 1: Login to Railway
------------------------
Run this in your terminal (opens browser for auth):

    railway login

This will open https://railway.app - sign in with GitHub/Google/Email

STEP 2: Deploy Automatically
----------------------------
After login completes, run the automated script:

    ./RAILWAY_DEPLOY.sh

This handles everything:
- Creates Railway project
- Adds PostgreSQL database  
- Sets environment variables
- Deploys your app
- Runs database migrations
- Seeds sample data

OR deploy manually:

    railway init
    railway add --database postgres
    railway variables set ANTHROPIC_API_KEY=your_key
    railway up
    railway run npm run db:push
    railway open
